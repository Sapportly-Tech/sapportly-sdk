# Сообщить об уязвимости

Не открывайте публичный GitHub Issue для дыр в подписи webhook, утечки ключей или обхода scopes.

Напишите на **ac@sapportly.pro** с темой `SDK security`. Опишите затронутые версии Sapportly TypeScript SDK (`@sapportly/sdk`), runtime и шаги без реальных секретов.

Мы ответим и, если подтвердится, выпустим патч и запись в CHANGELOG.
